# 证据使用指南（v2.0）

## 证据卡 → 板块映射

| 证据卡 | 字段 | 用于哪些板块 |
|---|---|---|
| A 当前 Listing 内容 | 标题、五点、描述、后台 Search Terms、A+ 模块、Q&A | A / B / C / D / F |
| B 评论分析 | 评分、星级分布、近期评论时间序列、高频差评痛点 | H（仅评分与趋势，不看评论数） |
| C 竞品关键词 | Top3 竞品 ASIN、词分级、月搜索量、竞品 VOC | A3 / D1 / D3 / G3 |
| P 参数信息 | Product Information 各字段分组 | F1 / F3 |
| E 内容资产 | 主图与副图 → E1；A+ 截图 → E2；产品视频 → E3（**E1 无视频检查点，视频扣分只归 E3**） | E1 / E2 / E3 |
| D 关键词与流量 | 固定核心词池、机会词池及需求权重、日级 BSR 走势预计算（bsrTrend，I3 唯一数据源）、词族合并结果 | G1 / G3 / I3 / J2 |
| 广告报表（可选） | 清洗后的 5 层汇总 + 逐词判断结果 | 广告域（不进 100 分） |

## 取证范围必须一致

固定站点、子 ASIN、日期 / 时窗、渠道（自然 vs 广告）、词池、基期权重、抓取范围。不可混用父体 Listing 与单子 ASIN、自然与广告、历史与当日；分母与排除原因须可回溯。

## 审计前必须先冻结（看样本结果之前就定好，不许边看边加）

品类关键配置检查清单、核心意图清单及权重、合格配置/场景词池、品类购买问题清单及权重、能力—用途关系清单、固定核心词池、机会词池及需求权重、基期与观测天数。

> 以上清单由取证链路的预计算块与品类默认口径提供；证据卡未覆盖的清单项按「待核」处理，不许现场发明。

## 待核 / N/A 判定要点

- **待核（pending）**：无权限、抓取不全、变体归属不明、缺竞品基准、刻度未冻结、H/I/J 无同类基准。score 必须为 null，pendingReason 写明原因。**禁止默认 0 或满分。**
- **N/A（na）**：有明确品类 / 产品 / 业务证据支持不适用（如类目不允许 A+ 时 E2 相关项、无适用宣称时 D2）。naReason 写明依据。**不能用 N/A 掩盖缺数据。**
- 「确认缺失」才扣分：相关页面或后台字段已完整取证、内容确实没有 → verified 低分 + deductions。
- D 卡预计算块是 G1/G3/I3/J2 的唯一数据源：词级数字一律引用预计算块，不得编造；预计算块不可用时 G/I/J 相关项判待核。
