# 生成内容标识与文生文日志

默认开启，无新增环境变量。平台自定义服务编码为 `ZQYK-SELLEROS`，不是官方分配的备案编码。模型信息只在文生文审计中记录调用时的 `AiGatewayModel.displayName`，不打印模型 ID；目录缺失时为 `null`，不伪造名称。

图片在最终显示坐标的右下角写入“AI生成”，实际字形高度为最短边的 6%，使用深色背景、白色文字。PNG 文件写入关键词为 `AIGC` 的 tEXt 文本块，JPEG/WebP 写入含 `AIGC` 字段的 XMP，输出后回读校验尺寸和标识。先完成裁剪、尺寸处理，再标识；对外原图也有标识。前端裁剪保存时在服务端另存带标识文件，返回新 URL，原上传文件不覆盖。

视频全程显示同样的像素水印，输出为 MP4/H.264，音频流复制保留。MP4 `AIGC` 元数据通过 `use_metadata_tags` 写入；交付前使用 ffprobe 回读标识、尺寸、音轨数量和时长。视频需要解码/重编码，会增加交付时间和 CPU 占用，并可能改变文件体积、画质及色彩表现。动画/不支持的图片格式、损坏文件、标识或校验失败均不交付未经标识的文件。

隐式标识各字段按字符串写入。已有可读取的规范生成方信息保留，传播方填写本平台编码；没有来源标识时以平台编码创建首次记录。产物编号取业务产物身份；同一产物恢复时编号不变。

接入出口：主生图、文生图、图生图、局部重绘、网关人像/拆图、车泰斗生成和导入产物、客户素材图、RPA 图片/视频、通用/动作复刻/带货/内部代理/美妆/分镜网关视频以及客户曦灵视频。普通上传、参考图、审核快照、已有历史文件不批量修改。前端继续使用原任务查询和文件 URL，无需新增水印参数。

图片执行器保存内部 URL 交付回执 `deliverySource` 和已成功生成的网关任务 ID；内联图片字节不写入数据库，恢复时从原网关任务重新取得并处理产物；标识/托管失败后复用回执及原生成任务恢复交付，不重新提交收费生成。`deliverySource` 从 HTTP 响应中移除。网关视频保留原任务状态及网关 ID，标识失败时不写成功、不结算终态，供应商重试或原任务读时对账继续处理。RPA 标识失败返回可重试错误，保留原生成状态，由同一供应商回执重试，不转成可触发重新生成的失败席位。

视频原始文件先以 private ACL 保存至 `aigc/sources/`，完成标识的成品保存至 `aigc/videos/v1/`；同一产物回调、轮询重复到达时复用成品。文件通过磁盘流转，不将网关视频整段读入 Node 堆。新增交付路径与审核快照一样，不签发客户端覆盖凭证。

文生文只通过现有 Nest Logger 打印 `AigcTextAudit` / `event=aigc.text`，没有独立日志文件、保留期、定时清理或数据库日志表。包含 UTC 时间戳、请求/调用编号、真实用户 UID、业务问题、`displayName`、输入审核状态及生成状态；不记录完整回答、系统提示词、密码、Token 或模型 ID。HTTP 中在全局参数审核前建立上下文；内部代理解析用户后补 UID，车泰斗后台恢复按账本 ownerId 关联。已登记文生文入口被审核提前拒绝时也打印未生成记录；普通资料接口和图片/视频生成入口不会因此打印为文生文日志。新增文本路由需同步 `text-audit-routes.ts` 的提前拒绝登记，共享 Provider 的正常调用日志不依赖路由名单。流式请求提前结束记录 CANCELLED，异常记录 FAILED，不伪造输出审核结果。

部署先执行 `npx prisma db push` 和 `npx prisma generate`，本次仅为 GeneratedImage、ImageGenItem 增加可空的内部回执 JSON 字段，无新增表。Docker runtime-base 已安装 FFmpeg 和中文字体，包含无 PDF 版本；本机开发需自行安装 ffmpeg、ffprobe 及可渲染中文的字体。不需要为文本日志新增挂载；是否采集/保存控制台输出沿用现有运维配置。

测试：`npx jest --runInBand 'aigc/.*spec'`。视频真实字节测试需要 PATH 中有 ffmpeg 和 ffprobe，缺少时明确跳过；其他测试仍验证失败不交付、恢复不重新生成、日志并发隔离和技术凭证排除。测试仅生成本地色块、音频测试信号，不连接收费生成服务。

参考：[GB 45438—2025](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F32EA2A561F1886CD8D606513512D547)、[sharp XMP](https://sharp.pixelplumbing.com/api-output/#withxmp)、[FFmpeg MP4](https://ffmpeg.org/ffmpeg-formats.html#mov_002c-mp4_002c-ismv)。元数据及水印功能不代表备案手续已完成。
