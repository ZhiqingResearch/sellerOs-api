# 类目分析上线说明

依据 2026-09-18 开发说明、标准化提示词、交付原型及《类目分析-文档变更对照》。计费继续遵守用户已确认的覆盖指令：取消固定 20 积分；成功三方请求按公共 MCP_CALL 定价，AI 按真实账单与模型售价倍率结算。创建、失败请求、缓存命中和 Keepa 额度探测不计费；部分接口成功后失败仍保留实际费用。

## 入口与任务

- 市场前调 > 类目分析，原锚定类目选择器保留；增加最多 5 个英文关键词，前端支持逗号、顿号、换行分隔。中文词在创建或取数前拦截。
- `POST /api/category-analysis` 新增 `keywords?: string[]`、`plan?: cat|kw|mix`，categories 可为空数组，两种输入不能同时为空；同 requestId 不同参数返回 409。
- 仅关键词：PROCESSING → AWAITING_SELECTION，候选、关联词、头部 ASIN 持久化，刷新后可继续。这一步只结算实际反查数据调用，不调用 AI。
- `POST /api/category-analysis/:id/categories` 接收 `{categoryIds: string[]}`，只能选本人任务的 1–5 个候选；原子认领继续执行，相同确认幂等，已执行后不同选择返回 409。
- GET 详情新增 keywords、plan、resolution；历史页识别待确认状态。
- cat 保留原类目；kw 按关键词前 3 候选重新分析；mix 严格标题匹配不足 30 后尝试最后主词，仍不足则显示真实条数并回退 cat。月销历史同步按交集 ASIN 过滤。

## 取数与统计

- 导入解析 API 保留、无页面入口；实时分析不再依赖导入样本。关键词 TopASIN 前 300 并入最多 50 个新品，每批 100 获取详情；无价格不入样本，有效样本不足 30 明确失败。
- 月销历史：头部 200、每批 10、18 个月取最近 12 个完整月；缺失或零销量不进入当月，历史不复制当前卖家身份。日趋势：头部 20、近 90 天，卖家数最近 14 天中位，评论按实际跨度折月。
- 关键词五接口分别降级、逐词缓存；用户输入词排在表前并标注。增加新词只补新词，原词不重复查询。
- Keepa 仅前 10 商品，buybox=1，按 tokensLeft/3 截断；卖家画像按日缓存，零额度不请求。成功商品批量与卖家批量各算一次 MCP 请求，不按外部 token 数扣积分。
- 公共市场数据缓存保存在后端 CategoryAnalysisCache，浏览器刷新、其他用户和服务重启均可复用。按用户最新要求，SIF 成功取数后固定有效 14×24 小时，读取不续期；Keepa 保持当天有效。失败不落缓存，过期响应不读取，同键再次成功时覆盖。
- SIF 缓存键区分站点、端点、请求方式及筛选参数；批量 ASIN/关键词顺序不影响命中。系统自动生成的近 90 天趋势按商品和窗口长度复用，避免跨天日期变化绕过缓存；显式不同时间范围仍隔离。逐词缓存保留批次原过期时间，增加新词只查询缺失词。同进程并发相同请求合并，数据库复用已完成结果（不提供多实例同时首次未命中的分布式锁）。
- 页面选类目使用本地树；轮询和历史详情只读任务。确认分析才进入后端取数，缓存命中不计 SIF 请求、不扣三方积分；重新生成 AI 报告仍按实际 AI 账单结算。缓存仅存公开市场响应，不含凭证或用户报告。
- 卖家画像少于 6 条三项卖家指标为空，覆盖不足 80% 仅出头部 BuyBox 集中度；头部 Amazon 占比不触发整类目硬性结论。新品不足 15 或新品榜补样不足时成功率和周期为空。
- A+/LQS 退出展示与模型输入，替换为 BS 标签密度；头部动态六项。24 项指标及 8 项规则由后端计算，AI 不重算。六节报告只使用新提示词，保留数据核对。
- 不回退随机数或演示数据，缺数为 null；样本年销售额不代表整个市场，专利/供应链人工确认。

4. 数据费和 AI 费用各有幂等键，任务累计与真实消费同事务；重复轮询、重复确认和重复账单不重复扣费。数据库验证脚本强制回滚全部测试写入。
