# 组合提示词恢复 PRD 契约（2026-10-08）

模板版本：`a1-20261008-compose-prd-v7`。本方案替代本次尚未部署的 v6 硬条件组装方案。

PRD v2.0 F12/F13、§8.4、A7/A8 要求模型组织本次适用的修改与保留要求，后端核验选择、文案和有效答案；生图使用确认后的完整指令，不固定追加 facts 全文、风险卡或共用模板。PRD 不要求逐条硬条件检查和英文逐字重复。

修复内容：

- 新模板取消 `hardConstraintChecks` 输出要求，facts 仍进入组合模型并参与事实冲突判断。
- 后端取消逐条检查与英文嵌入门槛。旧模板返回的扩展字段不保存到新组合产物，原始回执不变；明确报告硬事实冲突却声称 ready 的结果仍拒绝。
- 生图入口取消 `PRODUCT_CONSTRAINT_CHECK_REQUIRED` 闸门，不再追加事实原文或结构清单。继续保留后续已支持的画布比例指令与尺寸参数，组合指令本身不改写。
- 选择覆盖、精确文案、目标语言、有效决策、当前草稿/资料版本、权限及模型就绪检查保留。冲突问题成功返回 NEEDS_RESOLUTION，但不能生图；正常结果 READY 才能生图。
- 遵循 2026-10-07 后续联调规则：不新增自动付费重试，失败调用免费。JSON 或业务契约不合格仍失败，用户手动重新组织。

历史 Task/Call/Job 不迁移、不自动恢复、不改写已发请求。新任务使用 v7；旧模板/已有 Call 使用其冻结请求，校验不再因撤销的扩展字段逐字不一致失败。生图已提交的批次继续使用原冻结请求。

无需改表或调整前端接口。此修复取消额外门槛，不保证语义判断或模型效果永不出错，仍须实际样图核对；其他 JSON、文案和选择错误继续拦截。
