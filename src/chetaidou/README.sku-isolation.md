# SKU 资料隔离与原图型号文字（2026-10-07）

PRD v2.0 §4.4、D01 的历史型号隔离用于防止跨商品混用资料，不能仅凭母版出现 `C1S` 字样认定错误归属。原图文字作为观察记录保留，不自动确认参数或型号适用关系，也不自动替换为当前 SKU 名称。明确的归属证据或已确认事实与本次编辑要求矛盾时，仍阻断受影响的要求。

新模板版本为 `a1-20261007-sku-isolation-v5`。图片、拆解和保护文字不修改；资料隔离单独用 `facts.dataIsolationRules` 表达。产品结构、品牌、型号、参数值及真实标识的保护规则继续生效。

开发库 `agent-dev-new` 已于 2026-10-07 发布修正版 v3。一次性历史修复脚本及其操作说明已删除，历史发布审计保留在数据库中。

新环境通过 [统一初始化入口](../../scripts/chetaidou/README.md) 加载正式的结构化事实卡 `scripts/chetaidou/preset-data/facts/cs1plus.json` 及来源全文，直接使用修正后的规则，数据库版本从 1 开始。初始化不依赖历史修复编号、旧版本或数据库 ID；已有环境的后续资料变更通过管理端发布。

代码部署并发布 v3 后，使用新建 COMPOSE 重新组织。历史 Task/Call 的模板、资料、答案和已提交请求仍使用冻结快照，不改写历史任务；已使用联想选项且资料版本变化时，按现有过期规则重新联想。

自动化验证覆盖原图型号文字、隔离规则与结构硬条件的独立传递、合法文案组合、旧模板冻结，以及初始化资料完整性、来源校验和已有事实卡保护。模型是否遵守语义规则仍需实际样图联调，模拟响应测试不代表真实模型效果已验证。
