# 车泰斗：本人上传图片移除接口

更新日期：2026-10-07。适用于工作台左侧母版列表中的「用户上传」图片；后端已实现，前端按本文接入。无需新增数据库字段或执行初始化脚本。

## 1. 接口

```http
DELETE /api/chetaidou/images/8
Authorization: Bearer <token>
```

- `8` 是母版列表返回的 `items[].id`，不是预览墙的结果 ID、任务 ID 或拆解 ID。
- 无请求体，无需 `idempotencyKey`、`skuId` 或 `draftRevision`。
- 沿用车泰斗权限 `tool.ai_creative_studio.chetaidou`。
- 只允许当前登录用户移除自己上传的图片；超管调用这个 C 端接口也不能移除其他用户的上传图。
- 系统预置母版不能通过此接口移除。

成功返回 **HTTP 200**：

```json
{
  "imageId": 8,
  "removed": true
}
```

同一用户重复移除自己的同一图片，仍返回上述成功结果。网络中断、响应丢失时可以安全重试这个 DELETE 请求。

调用示例（沿用项目现有的鉴权请求封装即可）：

```ts
await api.delete(`/api/chetaidou/images/${image.id}`)
```

若请求封装的 `baseURL` 已包含 `/api`，请使用 `/chetaidou/images/${image.id}`，避免重复前缀。

## 2. 移除范围

这是从工作台母版列表中移除，不是物理删除文件：

| 对象 | 移除后的行为 |
|---|---|
| 母版列表 | 不再返回该图片，分页 `total` 同步减少 |
| 母版详情、草稿入口 | 访问该图片返回 404 |
| 新建工作台操作 | 不能再从该母版发起新操作 |
| 已提交任务 | 保留并继续执行，移除操作不会取消任务 |
| 历史任务及预览墙结果 | 保留，原有查看、下载及任务操作按既有规则处理 |
| 积分 | 移除本身不收费、不退款；已提交任务仍按既有计费规则结算 |
| 原始图片文件、拆解、草稿记录 | 后端保留，不因移除清理 |

当前接口不提供撤销或恢复。用户需要重新添加时，重新上传并生成新的上传幂等键；不要复用原上传请求的幂等键，否则原上传接口会返回旧记录。

## 3. 前端接入

1. 母版列表接口 `GET /api/chetaidou/skus/:skuId/images` 已只返回系统母版和本人上传图。仅对 `sourceType === "USER_UPLOAD"` 显示「移除」按钮，`PRESET` 不显示。
2. 点击移除时阻止事件冒泡，避免同时触发切换母版；请求期间禁用该按钮。成功后提示「图片已移除」，重新请求当前 SKU 的母版列表及总数。
3. 移除的是当前选中图片时，清除该图片的选中状态、详情和草稿缓存，停止该图片的工作台轮询与自动保存，移除地址栏旧 `imageId`。取消或忽略旧图片在途请求的回写，避免旧详情重新覆盖页面。
4. 列表刷新后可选中第一张可用图片；没有图片则展示空态和「上传新图」。当前分页被删空且不是第一页时，回到上一页重新拉取；总数以服务端响应为准，不对重复成功响应重复减一。
5. 移除非当前选中图片时，保持现有工作台状态。删除事件不要顺带清空预览墙、取消后台任务或调用预览墙批量移除接口。
6. 多标签页或历史任务链接仍可能指向已移除母版。母版详情/草稿返回 404 时提示「该图片已不可用，请重新选择」，清理旧 `imageId` 并刷新列表，不无限重试。

建议在操作旁说明：「移除后将从母版列表隐藏，已提交任务和生成结果保留。」

## 4. 错误处理

错误返回沿用全局格式，例如：

```json
{
  "statusCode": 404,
  "code": "IMAGE_NOT_FOUND",
  "message": "图片不存在或无权移除",
  "timestamp": "2026-10-07T00:00:00.000Z"
}
```

| HTTP 状态 | code | 前端处理 |
|---|---|---|
| 400 | `IMAGE_REMOVE_NOT_ALLOWED` | 展示「只能移除自己上传的图片，系统母版不可移除」 |
| 404 | `IMAGE_NOT_FOUND` | 展示「图片不存在或无权移除」，刷新列表；不存在和其他用户图片统一返回此错误 |
| 400 | 不固定 | 路径 ID 非整数，请修正传参，提示使用中文兜底 |
| 401 / 403 | 沿用鉴权逻辑 | 登录过期或缺少车泰斗权限，走现有处理 |
| 5xx / 网络异常 | 不固定 | 保留当前状态，中文提示「移除失败，请稍后重试」 |

业务错误展示中文 `message`；不要直接展示异常堆栈或代码内容。

## 5. 联调验收

- 本人上传图：移除成功，列表和总数更新，详情及草稿访问返回 404。
- 重复点击、并发请求、丢失响应后重试：都返回成功，总数不被前端重复扣减。
- 普通用户和超管：均不能移除其他用户上传图。
- 系统母版：不显示按钮，直接调用接口也被拒绝。
- 图片尚未完成拆解、事实卡暂不可用：仍允许本人移除。
- 有在途任务或历史生成结果：移除不取消任务、不清空预览墙、不删除原文件。
- 当前图片、非当前图片、分页最后一张、整个列表最后一张：选中状态、地址栏和分页均正确处理。
